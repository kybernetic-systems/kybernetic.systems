# Typography

EB Garamond (serif) for everything people read; IBM Plex Mono for labels, metadata and notes. Both
are self-hosted. Sizes are fluid between a 390px and a 1280px viewport and set in `rem`, so browser
font-size preferences and zoom still apply. Resize the canvas to see them scale.
