# Spacing & Layout

Named spacing tokens replace the reference's scattered pixel values. Each bar shows the token at the
current canvas width.

<SpacingScale />

## Widths

| Token                                         | Value              | Use                      |
| --------------------------------------------- | ------------------ | ------------------------ |
| `max-w-page`                                  | 1160px             | Page container           |
| `max-w-statement`                             | 820px              | "Our Cause" statements   |
| `max-w-article`                               | 760px              | Blog post column         |
| `max-w-narrow`                                | 700px              | Centered calls to action |
| `max-w-measure-sm` / `measure` / `measure-lg` | 30em / 34em / 42em | Reading measures         |
